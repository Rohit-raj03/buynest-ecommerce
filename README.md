# 🛍️ BuyNest – Modern E-commerce Web App

BuyNest is a modern, responsive e-commerce web application built with **React**, **React Router**, **Context API**, and **Tailwind CSS**. It provides a clean shopping experience with product browsing, filtering, searching, cart management, and protected authentication.

---

## 🚀 Features

### 🔐 Authentication

* User Registration
* User Login
* Protected Routes
* Public Routes
* Logout Functionality
* Authentication using Local Storage

### 🛒 Shopping

* Browse Products
* Product Details Page
* Related Products
* Add to Cart
* Increase / Decrease Quantity
* Remove from Cart
* Cart Total Calculation
* Persistent Cart using Local Storage

### 🔍 Product Filtering

* Search Products
* Category Filter
* Sort Products

  * Featured
  * Newest
  * Price: Low → High
  * Price: High → Low
  * Top Rated

### 🎨 UI & UX

* Responsive Design
* Dark Theme
* Orange Accent Theme
* Animated Hero Section
* Flash Sale Countdown
* Custom Scrollbar
* Toast Notifications
* Smooth Navigation
* Auto Scroll to Top on Route Change

# ⚙️ Installation

Clone the repository

```bash
git clone <repository-url>
```

Move into project

```bash
cd buynest
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Build project

```bash
npm run build
```
